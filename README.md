# JavaScript Mini Projects!

This repository contains a curated set of **8 JavaScript mini projects** developed to strengthen core frontend concepts such as DOM manipulation, event handling, browser APIs, and logic building.  
Each project is **individually deployed** and accessible via live demos.

---


## 📂 Projects Overview

| # | Project Name | Description | Live Demo |
|---|-------------|------------|-----------|
| 1 | Text to Speech Converter | Converts written text into spoken audio using the Web Speech API | [View Demo](https://sabat.gayatri-235396208.workers.dev) |
| 2 | Number Guessing Game | Guess a number between 1–100 with limited attempts | [View Demo](https://number-guessing-game.gayatri-235396208.workers.dev) |
| 3 | QR Code Generator | Generates QR codes from text or URLs | [View Demo](https://qrcode-generator.gayatri-235396208.workers.dev) |

| 6 | Digital Clock | Displays real-time local system time | [View Demo](https://digitalclock.gayatri-235396208.workers.dev) |
